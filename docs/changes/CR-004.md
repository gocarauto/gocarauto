## 1. Problem Statement
1. **Critical Telemetry Link Offline Error on Production**:
   - The online dashboard at `gocar-staff.pages.dev` displayed a blocking error `CRITICAL: TELEMETRY LINK OFFLINE` with an empty black dashboard.
   - Root cause: Production backend connects to TiDB / MySQL on Render. Queries in `reportController.js` (`getDashboardSummary` and `getRevenueForecast`) used SQLite-specific syntax `date('now', 'start of month')` and `date('now', '+7 days')`. In MySQL, `DATE()` takes only one argument, triggering `ER_WRONG_PARAMCOUNT_TO_NATIVE_FCT` and throwing HTTP 500.
2. **Login Helper Credentials Visible**:
   - The login screen displayed demo credentials box at the bottom.
3. **Staff Direction Switcher**:
   - The floating 3-option theme widget in the bottom right was cluttering the UI.

## 2. Blast Radius & Impact Assessment

## 3. Implementation Details
1. **Cross-Dialect Parameterized Date Evaluation**:
   - In `reportController.js`, `notificationController.js`, and `vehicleController.js`, calculated ISO date boundaries in JavaScript and passed them as standard query parameters (`?`).
2. **Dashboard Resilience**:
   - Replaced blocking full-page error with fallback default metrics and a non-blocking retry banner.
3. **UI Polish**:
   - Removed the default staff credentials box from `Login.jsx`.
   - Removed `<DirectionSwitcher />` from `Layout.jsx`.
