# CR-002: Comprehensive Front-End & UI/UX Hardening

## 1. Overview & Intake
- **Change Request ID**: CR-002
- **Target Applications**: `staff-interface/`, `customer-portal/`
- **Severity**: Critical / High
- **Status**: Completed (Remediated & Verified)
- **Intake Summary**: Following comprehensive front-end audit across both applications, multiple critical and high-priority bugs were discovered: hardcoded localhost URLs, pop-up blockers on invoice viewing, silent form failure on service request creation, unvalidated multi-step booking, un-debounced search queries, exposed developer switcher in production, CSS typos, contrast issues, and accessibility deficiencies.

---

## 2. Issues to Remediate
1. **Critical 2.1**: Replace hardcoded `http://localhost:3000` URLs in `VehicleList.jsx` and `ConsignmentHub.jsx` with dynamic API URLs. In `VehicleFleet.jsx` (customer portal), fix relative `/api` passport download. Configure dev server proxy in `customer-portal/vite.config.js`.
2. **Critical 2.2**: Eliminate asynchronous `document.write` in `InvoiceList.jsx` and `ServiceHistory.jsx` that triggers browser pop-up blockers.
3. **High 3.1**: Add error state banners to `ServiceRequestForm.jsx` to prevent silent catch failures.
4. **High 3.2**: Add vehicle validation and empty state in `ServiceBooking.jsx` Step 1 before allowing transition to Step 2.
5. **High 3.3**: Debounce real-time search inputs (300ms) in `CustomerList.jsx` and `VehicleList.jsx`.
6. **High 3.4**: Remove developer `<DirectionSwitcher />` from production Customer Portal `Layout.jsx`.
7. **Medium 4.1**: Clean up native alerts and provide in-app feedback.
8. **Medium 4.2**: Add `htmlFor` and `id` across form controls for WCAG 2.1 compliance.
9. **Medium 4.3**: Wire customer portal search bar to submit query to `/history?search=...`.
10. **Medium 4.4**: Support bidirectional RTL/LTR layout in Staff Interface `Layout.jsx`.
11. **Low 5.1**: Fix contrast on language button in Customer Login light mode.
12. **Low 5.2**: Fix `backdrop-p-10` CSS class typo in Staff `Login.jsx`.
13. **Low 5.3**: Make telemetry calculation resilient in Customer Portal `Dashboard.jsx`.
14. **Low 5.4**: Add customer self-service password change in `Settings.jsx`.

---

## 3. Impact & Risk Assessment
- **Side-Effect Classification**: Front-End Quality & Reliability Improvement
- **Reversibility**: Reversible via Git revision.
- **Workflow Impact**: Eliminates broken links on external/cloud environments, restores invoice viewing on mobile browsers, prevents user confusion and double-submissions.
