# Change Request CR-006: Comprehensive Application Responsiveness & Mobile/Tablet Adaptation

- **Date:** 2026-11-09 / 2026-11-10
- **Phase:** Phase 10 (Change Requests)
- **Role:** Builder & Scribe
- **Tooling / Framework:** `pbakaus/impeccable` Adapt Engine (`.agent/skills/impeccable/reference/adapt.md`)

## Objective
Execute complete mobile and tablet responsiveness adaptation across both GoCar Auto frontends (`customer-portal` and `staff-interface`). Implement thumbs-first ergonomics, persistent mobile bottom navigation bars, table-to-card adaptive layouts, responsive HUD telemetry cards, and touch-target compliance ($\ge 44\times 44\text{px}$) across all viewports (360px–2400px).

## Scope of Changes

1. **Customer Portal Mobile Adaptation (`customer-portal`):**
   - **Persistent Mobile Bottom Bar (`Layout.jsx`):** Fixed bottom navigation bar for viewports `< 1024px` with quick access to Dashboard, Fleet, Book Service (prominent center CTA), History, and More (Drawer trigger).
   - **Safe Area Inset Spacing:** Added `pb-24 lg:pb-8` to main scroll view ensuring no floating buttons or text are covered by the mobile nav bar.
   - **Mobile Expandable Search:** Compact search toggle in the top bar with animated expand/collapse for mobile viewports.
   - **Vehicle Cockpit Stage Fluidity (`Dashboard.jsx`):**
     - Scaled vehicle hero stage to `h-[360px] sm:h-[440px] md:h-[530px]` on mobile.
     - Transformed desktop absolute HUD telemetry cards into a clean, dedicated 3-card mobile vitals tray beneath the stage, eliminating overlay collision bugs on narrow phones.
     - Segmented bottom action dock made horizontally swipable with `no-scrollbar`.
   - **Adaptive Data Views (`ServiceHistory.jsx` & `InvoiceList.jsx`):**
     - Dual representation: `< md` displays stacked operational cards (Service Type, Date, Vehicle, Cost, Status, and View/PDF actions); `md+` retains the full data table.
   - **Modals to Bottom Sheets (`SellCarModal.jsx`):**
     - Transformed fixed center dialog to a native-feeling mobile bottom sheet with rounded top corners and thumb-friendly controls.

2. **Staff Interface Mobile Adaptation (`staff-interface`):**
   - **Persistent Staff Bottom Bar (`Layout.jsx`):** Fixed bottom operations deck on mobile devices for fast workshop floor access (Deck, Orders, Center Intake CTA, Fleet, Clients).
   - **Header Elasticity:** Compact title hierarchy with expandable mobile search toggle.
   - **Work Orders Table-to-Card (`ServiceRequestList.jsx`):**
     - `< md` displays high-contrast operational cards with Work Order #, Portal/Staff source pill, Date, Client/Vehicle, Assigned Technician, Total, and full-width "Manage Work Order" button.
     - `md+` displays the master 7-column table.
   - **Vehicle Fleet (`VehicleList.jsx`) & Client Registry (`CustomerList.jsx`):**
     - Dual presentation: responsive cards on `< md`, master tables on `md+`.

3. **Unified Verification Gate & Auditing:**
   - Unified verification script `npm run verify` passed with 0 errors (34 backend unit/security tests, 0 ESLint errors in staff and customer frontends, 2 clean Vite production builds).
   - `valdoz audit --strict` passed cleanly (0 secrets, 0 unpinned packages, 0 placeholders).
