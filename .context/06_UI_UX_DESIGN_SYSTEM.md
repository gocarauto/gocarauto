# UI/UX Design System

*Note: This file serves as the foundation for the Stitch MCP token layout engine.*

## Philosophy
The UI must deliver a premium, "Elite" aesthetic. It eschews generic templates in favor of highly customized, precision-engineered interfaces.

## Color Tokens (Example Schema)
- `color-surface-base`: #0B0C10 (Deep Space)
- `color-surface-elevated`: #1F2833 (Midnight Blue)
- `color-brand-primary`: #66FCF1 (Electric Cyan)
- `color-brand-secondary`: #45A29E (Teal)
- `color-text-primary`: #C5C6C7 (Soft Silver)

## Typography Tokens
- `font-family-primary`: 'Inter', sans-serif (English) / 'Cairo', sans-serif (Arabic)
- `font-weight-regular`: 400
- `font-weight-semibold`: 600

## Components Layout Engine
1. **Glassmorphism Panels**: UI cards use semi-transparent backgrounds with a slight backdrop blur to overlay authentic automotive imagery.
2. **Micro-Animations**: Buttons and links feature 200ms ease-in-out hover transitions. Modals fade and slide in from the bottom.
3. **Spacing**: Base spacing unit is 8px. Use multiples (8, 16, 24, 32) for padding and margins to maintain a rigid, predictable grid.

## Forms & Inputs
- Minimalist borders.
- Floating labels.
- Real-time validation feedback with subtle color shifts (Red for error, Green for success) rather than aggressive alert boxes.
