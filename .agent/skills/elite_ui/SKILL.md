# Elite UI Design Standards

When building or modifying UI components for the GoCar Auto applications (Staff Interface & Customer Portal), you MUST adhere to these premium design principles:

## Core Principles
1. **Rich Aesthetics**: The design must feel extremely premium and state-of-the-art. Avoid generic or flat, outdated designs.
2. **Glassmorphism**: Utilize glassmorphic effects (translucent backgrounds, subtle borders, backdrop blurs) where appropriate. See [glassmorphism.css](file:///home/akhalil/AntiGravity/GoCar%20Auto/.agent/skills/elite_ui/examples/glassmorphism.css) for implementation details.
3. **Color Palette**: Use curated, harmonious color palettes (e.g., sleek dark modes, vibrant but controlled neon accents for key actions). 
4. **Typography**: Use modern Google Fonts (e.g., Inter, Roboto, or Outfit) instead of browser defaults. Ensure proper hierarchy and readability.
5. **Micro-Animations**: Add subtle transition and hover effects to interactive elements (buttons, cards, links, form inputs) to make the interface feel alive and responsive.
6. **No Placeholders**: Always replace placeholder visuals with high-quality generated images (using the `generate_image` tool) if real assets are unavailable.
7. **Consistency**: Ensure any new components align seamlessly with the existing design system, CSS variables, tokens, and utility classes.
